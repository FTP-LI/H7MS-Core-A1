# 通用控制板需求基线

2026-10-11，Docs v0.8.0。产品独立于 XGO 或特定机器人；MCU已选 STM32H735VGH6 + Direct SMPS。

| ID | 要求 | 关闭证据 |
| --- | --- | --- |
| G01 | 最小系统可重复启动；复位默认禁止输出；BOOT0/NRST/SWD可恢复 | 上电波形及坏固件恢复试验 |
| G02 | USB FS与UART上位链路，统一指令/状态语义 | 客户端、重连和超时报告 |
| G03 | 三路独立原生CAN，以及四组设备UART可同时工作 | 三路CAN+USB+四串口+IMU+存储组合测试 |
| G04 | 设备ID、能力、量纲、坐标、时间戳、有效性和错误统一 | 两类不同设备配置及适配器演示 |
| G05 | 配置校验引脚/定时器/DMA/队列/节点所有权 | 冲突配置被拒绝；不可意外使能 |
| G06 | 周期任务有截止时间；队列、内存有界 | 峰值时延、RAM高水位、溢出和故障记录 |
| G07 | 指令有序号/期限/控制权；检测上位与节点失联 | 故障注入与停止时间 |
| G08 | 底板独立禁止路径；默认停机 | MCU卡死/掉电/断线时执行器使能波形 |
| G09 | 参数与升级有版本/校验/恢复 | 断电和损坏配置恢复 |
| G10 | 发布可复现工程、图纸、BOM、协议、构建和接线说明 | 独立环境复现记录 |

保留的资源以[引脚规划](引脚规划.md)为准。采样时间及上下位机分工见[职责与IMU边界](共性研究/上下位机职责与IMU处理边界.md)。控制频率、节点数量、CAN FD速率和整板持续电流尚无实测，不在此提前写成已达到的指标。NOR不作为运行RAM；外部RAM仅在预算证明确有缺口时重新评审，不能挤占本轮已经保留的接口。
