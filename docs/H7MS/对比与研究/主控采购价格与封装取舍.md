## 3. 换封装能保留什么

H723VGH6、VGT6和ZGT6都属于1 MiB Flash的H723xG，具有三路原生FDCAN、560 KiB非备份RAM及4 KiB备份RAM。更换为LQFP不等于降低CPU或片内RAM规格；144引脚也不会增加片内RAM。具体频率/ECC、存储分区见[芯片复核](H723与H743数据手册复核及选型判断.md)。[ST H723数据手册DS13313 Rev 5](https://www.st.com/resource/en/datasheet/stm32h723vg.pdf)

| 选择 | 对A1的工程取舍 |
| --- | --- |
| VGH6 / TFBGA100 | 本体紧凑；当前这条报价和起订量不利于样机。尚无证据将价差完全归因于BGA工艺或整个系列缺货 |
| VGT6 / LQFP100 | 公开单价较低，本体14×14 mm，引脚外露便于探测和返修；但当前无商城现货，且100引脚的三路CAN与存储接口竞争仍需解决 |
| ZGT6 / LQFP144 | 当前有少量商城现货，更多引脚有利于接口安排；本体20×20 mm，须重新验证核心板尺寸、连接器和布线空间 |

封装本体尺寸不含全部焊盘/走线占用。上述制造与调试利弊是工程判断；不推断必须使用某个PCB层数，也不声称一定节省多少装配费。不同封装不是焊盘兼容替代，不能只改BOM料号。H723的100/144引脚存储接口差异及第三路CAN复用冲突见[外部RAM与封装分析](三路原生CAN与H723外部RAM方案.md)。

## 4. G473作为价格比较项

STM32G473xE具备170 MHz Cortex-M4F、512 KiB Flash、128 KiB RAM和三路原生FDCAN，三路共用3 KiB CAN报文RAM，可作为通信、采集和轻量姿态任务的进一步评估项。ST的RM0440将G473和G474均列为三路FDCAN；不能将所有G4型号视为三路CAN。[G473数据手册DS12712 Rev 5，首页及§3.33](https://www.st.com/resource/en/datasheet/stm32g473ve.pdf)、[RM0440产品功能表](https://www.st.com/resource/en/reference_manual/dm00355726-stm32g4-series-reference-manual-stmicroelectronics.pdf)

但当前价格下，G473VET6相对H723ZGT6仅节省11.20元/片（1片阶梯），应先确认这点差额是否值得减少RAM和计算余量。还没有证明A1完整混合负载在G473上满足截止时间，也未完成全部勘误、电源及引脚兼容审查；本轮仅列为成本补充研究项，不改选。

另有实际引脚陷阱：ST员工确认DS12712 Rev 5的表13错误地给PB10/PB11列出FDCAN功能，这两个引脚不能据此分配FDCAN3，应结合正确的表12及工具重新审核。此项不否定芯片有三路控制器，但影响具体布线。[ST官方答复，2026-03-05](https://community.st.com/stm32-mcus-products-25/stm32g473-fdcan-pinout-contradiction-163472)

## 5. 选型执行顺序

1. 明确样机/后续批量数量、单颗MCU预算、整板预算及核心板尺寸上限。
2. H723VGT6取得可用交期；H723ZGT6评估20×20 mm本体能否接受。按同数量比较实际可供货报价。
3. 对满足价格和机械条件的封装重做三路CAN、USB、串口、IMU及存储资源矩阵；按无外部RAM方案进行基础预算。
4. 仅当G473等方案的整板节省足够明确且负载验证通过，再考虑缩减主控资源。N657仍按其独立评估核算启动存储、供电和装配总成本。
