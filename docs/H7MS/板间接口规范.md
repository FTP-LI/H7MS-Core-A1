# 板间接口规范 v0.8 草案

> 版本说明：本文保留 v0.8 输入。当前 v0.9 核心/扩展分工、引脚、连接器和加热要求以[工程规划](工程规划/README.md)为准；电源与通用方法仅在不冲突时沿用。

两组 50 位仅为本轮逻辑分配，不沿用 H743 v0.7 的插针编号。连接器系列、朝向、堆叠高度和机械防呆在 PCB 阶段冻结；[逐针 CSV](数据/板间接口_J1_J2_草案.csv)用于现在的连线评审。

| 接口 | 电气及方向（相对于核心） | 默认行为 |
| --- | --- | --- |
| 5V_IN | 底板→核心，4.75～5.25V；多个接点并联，1.5A为设计预算 | 上游保护；入口可断电/测流 |
| 3V3_AUX | 核心→底板，所有引脚合计200mA预算 | 不能由底板另一个3.3V稳压器反向并联 |
| CAN1～3 | 3.3V TX输出/RX输入/STB输出；CANH/L留底板 | STB高，收发器待机 |
| UART1～4 | 3.3V TX输出/RX输入/DIR输出 | DIR低接收；不直接连接RS-232/485差分线 |
| UART8、UART7 | 备用上位及辅助 TX/RX | 使用前声明独占者及反相配置 |
| PWM1～4 | 3.3V输出 | 下拉低；前三路共享TIM2周期 |
| SPI3 | SCK/MOSI/CS输出、MISO输入，3.3V | CS高；总线不用于板外长线直接驱动 |
| I²C2 | 3.3V开漏，核心默认4.7k上拉 | 汇总所有上拉及线电容后定值 |
| BASE_VOLTAGE/CURRENT | 底板调理后0～3.0V模拟输入，参考GND | 上电/掉电时也不得超出MCU电气限值 |
| PWR_EN | 核心输出；10k下拉 | 默认禁止；由底板与独立硬件条件共同决定实际使能 |
| PWR_GOOD | 底板输入反馈 | 核心47k下拉，正常由底板驱动高 |
| ESTOP_N / BASE_FAULT_N | 低为停止/故障 | 核心47k下拉，未接底板视为不可使能；底板正常时驱动高 |
| PB1、PE10 | 预留3.3V信号 | 初始模拟高阻，不承诺其他复用 |

板间共地，多接地点为信号回流和电源返回；电机大电流另走底板。NC 位不使用，不得借其暗接电源。热插拔、隔离、长线ESD与安全停止需要底板专门设计，目前接口没有热插拔能力承诺。

SWD/BOOT0/NRST 采用核心板本地恢复接口，避免底板外设绑死启动模式。若后续改连接器或跨板电压，必须同步改 CSV、原理图及固件板级定义。
