# H7MS-Core-A1主控选型与资源预算

整理日期：2026-09-11；性质：现有基线说明、讨论建议与待验证预算。

阅读顺序更新（2026-09-15）：先通过[机器人上下位机架构与资源调研](09_机器人上下位机主控架构与资源调研.md)确定任务分工、设备配置和端到端预算，再使用本文比较芯片与封装。当前保留H743是评估基线，不代替完整系统需求分析。

| 项目 | 状态 | 说明 |

本次整理没有替换主控，也没有把讨论中的建议升级为硬件冻结结论。引脚与接口仍分别遵循Pin Plan v0.7和Stack Interface v0.7。

## 2. 封装权衡

| 料号 | 封装本体尺寸 | 对项目的意义 |
| --- | --- | --- |
| STM32H743VIH6 | TFBGA100，8×8 mm，0.8 mm球距 | 保持紧凑；需评估BGA扇出、装配、检查与返修能力 |
| STM32H743VIT6 | LQFP100，14×14 mm | 引脚外露便于探测和返修，但封装变大，外设分配仍需完整复核 |
| STM32H743ZIT6 | LQFP144，20×20 mm | 更多引脚有利于扩展和资源分配，代价是占板面积增加 |

尺寸和型号来源：[ST H743VI](https://www.st.com/en/microcontrollers-microprocessors/stm32h743vi.html)、[ST H743ZI](https://www.st.com/en/microcontrollers-microprocessors/stm32h743zi.html)。工程利弊为本项目判断；封装本体尺寸不等于包含焊盘与布线空间的实际占板面积。

决定前需要核心板尺寸上限、连接器位置、生产工艺和成本报价。任何封装更换都必须复核电源引脚、AF、模拟通道、PCB封装和J1/J2逻辑映射，不能直接替换料号。

## 3. 主控系列比较

| 候选 | 最高主频/内核 | 片内Flash | RAM量级 | 针对A1的评估 |
| --- | --- | --- | --- | --- |
| [H743VI](https://www.st.com/en/microcontrollers-microprocessors/stm32h743vi.html) | M7，480 MHz | 2 MB | 约1 MB | 当前基线，保留固件、策略和多任务缓冲余量 |
| [H723VG](https://www.st.com/en/microcontrollers-microprocessors/stm32h723vg.html) | M7，550 MHz | 1 MB | 564 KB | 主频更高，但存储更少；需测试实际策略，不能按频率直接替代 |
| [H750VB](https://www.st.com/en/microcontrollers-microprocessors/stm32h750vb.html) | M7，480 MHz | 128 KB | 约1 MB | 若固件超过片内容量，将增加外部存储和启动实现工作；降本收益待报价 |
| [H745ZI](https://www.st.com/en/microcontrollers-microprocessors/stm32h745zi.html) | M7 480 MHz＋M4 240 MHz | 2 MB | 约1 MB | 可研究分核调度，但增加核间通信、共享数据与调试工作 |

表中容量为产品标称摘要，不是单块连续可分配RAM。主频上限也不是已验证的本板运行频率。H7R3/H7S3曾作为外部存储架构候选讨论，本次不推进迁移；完整电气兼容性、成本、供货和性能比较均未完成。

2026-09-15四板原理图调研补充：H743VI提供**2路FDCAN**，H723VG提供**3路FDCAN**。若产品需要三条独立片内CAN，H723具备明确外设收益，应与Flash/RAM容量同时评估；如果两条足够，继续保留H743的存储余量。D_MAIN的第四路CAN来自MCP2518FD，需要额外SPI、IRQ和驱动预算。以太网也需在引脚冻结前决定，不能假定当前v0.7已具备可用网口。来源：[ST H743VI](https://www.st.com/en/microcontrollers-microprocessors/stm32h743vi.html)、[ST H723数据手册](https://www.st.com/resource/en/datasheet/stm32h723vg.pdf)；详见[四板比较](11_参考控制板共性需求与选型结论.md)。

## 4. 主频、Flash和RAM如何取舍

- Flash用于固件、只读模型参数和恢复代码；QSPI可扩展存储容量，但不能当作低延迟工作RAM。
- RAM用于运行状态、任务栈、模型激活/临时工作区、通信及日志缓冲。权重从Flash读取时无需全部复制到RAM。
- 先确认容量、各内存区域的可达性及峰值余量，再判断计算是否能在周期内完成。总容量有空余不代表DTCM或某个DMA可访问区有空余。
- 如果RAM紧张且时序达标，优先保留大RAM；如果容量宽裕而计算超时，先检查算法、编译、数据放置和量化，再评估更快主控。
- 主频不是完整性能指标：缓存、存储等待、总线竞争和实现方式都会影响最坏耗时。

作为纯主频比例示例，550/480约为1.146；假设其他条件完全相同、耗时与主频成反比，2 ms计算约变为1.75 ms。这不是H743与H723的实测预测，两者缓存和存储结构不同。

## 5. 基础平台预算与可选推理算例

基础选型先覆盖[通用验证配置P0～P4](10_通用控制平台需求基线.md)：上位通信、串口/CAN、采集、日志、升级布局和故障路径的组合负载。按总线/节点数、报文长度、频率及各RAM区域记录预算；不根据单一机器人的关节数倒推平台上限。

可选推理基准为45→128→128→12的全连接MLP，三层带偏置；它不限定平台设备数量或算法输入输出：

```text
参数数量 = (45×128+128) + (128×128+128) + (128×12+12)
         = 23,948
FP32参数 = 23,948×4 = 95,792字节，约93.55 KiB
```

INT8参数容量约24 KB仅表示量级；偏置常采用更宽类型，并有量化比例、元数据和对齐开销，实际数值以转换报告为准。激活区和临时工作区另行测量。

| 指标 | 当前目标/记录要求 | 当前结果 |
| --- | --- | --- |
| 策略频率 | 200 Hz，即5 ms周期 | 未测 |
| 策略推理最坏耗时 | ≤2 ms | 未测 |
| 整个控制周期最坏耗时 | ≤4 ms | 未测 |
| CPU余量 | 至少20%；周期余量和总体CPU占用分别记录 | 未测 |
| 内部Flash | Boot、固件、内部权重、恢复路径分别统计 | 待生成链接map |
| 各RAM区域 | 静态数据、堆栈峰值、AI工作区、DMA缓冲分别统计，报告剩余字节 | 待链接map与运行测量 |
| DMA与Cache | 按实际DMA控制器检查可达性、对齐和所有权切换 | 待验证 |
| 数值误差 | PC/ONNX与H7固定输入对比，阈值随控制要求确定 | 待定义/验证 |

这些时序目标仅沿用[可选RL基准](05_RL策略部署.md)，不作为基础平台验收条件，也没有新增硬件性能承诺。板级RAM预算尚未分配，不使用假定的占用值作为选型依据。

验证时记录MCU料号及硅版本、时钟、电源档位、编译器及优化选项、推理工具版本、模型哈希、权重位置和Cache配置。分别测量推理单独运行和IMU/执行器通信/TF日志并发时的平均、P99、最大耗时、任务栈峰值及错误计数。

## 6. 重新选型的触发条件

1. 机械尺寸或制造能力不支持当前BGA方案：先评估H743其他封装。
2. 优化后最坏时延仍超出配置的截止时间：用同一通信/采集负载比较候选芯片，启用推理时附同一模型。
3. RAM区域或Flash升级布局无法容纳计划功能：调整模型/存储方案或选择更大容量芯片。
4. 实际采购和生产报价显示明显收益：同时计算迁移、调试与测试成本。

候选方案只有形成资源报告、兼容检查和版本变更记录后，才能替换当前基线。尚未完成的工作统一跟踪于[项目状态与待办](08_项目状态与待办.md)。
