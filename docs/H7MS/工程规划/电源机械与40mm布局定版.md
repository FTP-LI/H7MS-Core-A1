# 电源、辅助器件与 40 mm 板组设计输入

2026-10-16，v0.9.3-design。用户确认：**核心板、验证板、后续应用板均不得超过 40×40 mm**。本版采用 39.8×39.8 mm、外形公差 ±0.1 mm，核心板与一块扩展板上下插合。优先级高于旧文档的单块 BASE-DBG、未定保险/开关/电容以及未定板形描述。

已确定器件订货型号、供电边界、连接更改、板型拆分和布局预留区域。**这是画原理图及开始 PCB 的输入；没有实际 EDA 原理图、逐元件布局、布线、ERC/DRC 或样机验收。**不可从布局框图直接生成生产文件。

各 BASE 都含自己的5 V入口、保险、总开关及软启动、AUX监视和相同 J1/J2。每套只装 **一个 CORE＋一个 BASE**；四款 BASE 是可更换验证板，不是四层并联背板。需要同时控制 CAN 与多个485总线时，采用两套完整节点，通过 BASE_CAN 的 DEV4 与 BASE_485 的 DEV4 协作。SPI验证使用两套 BASE_LINK，分别装 MASTER/SLAVE方向电阻。各节点自行供电，链路接信号地，不并联电源输出。

各板的ESTOP是输入信号；硬件与门切断负载的验证电路仅在BASE_IO。CAN/485电机的实际停机还需驱动使能/动力电源链路配合，不能认为按下这个信号按钮已从硬件切断所有电机动力。

原 [原理图连接.csv](原理图连接.csv) 中 BASE_DBG 现在是**逻辑电路全集，不制造该整板**；实际画图按 [紧凑板原理图连接.csv](紧凑板原理图连接.csv)、[装配清单](紧凑板装配清单.csv)。此前七套 MCU 资源配置仍是电气能力配置，不再等于一块验证板的全部实装功能。NOR、RMII、驱动功率级等应用扩展仍需各自详细设计，尺寸上限同样40 mm；不假称已包含在本轮验证板。

拆分意味着旧计划“全部接口接上、单 MCU 同时满载”的整机测试不能原样执行。先做每板局部压力测试，再做两节点通信与故障联合测试；最终产品实际启用哪些功能，必须在对应应用扩展板上做同一 MCU 的并发测试。不能用两块板各自通过代替这一项。

## 3. 电源连接与预算

```text
受控5.1 V电源 → PH入口 → F1 2.5 A → FUSED_5V → TPS22975 → 5V_IN
                                                   ├ CORE TPS62132 → 3V3_D
                                                   │                 ├ MCU/IMU/控制逻辑
                                                   │                 └ TPS2553-1 → 3V3_AUX
                                                   ├ CORE 三CAN VCC
                                                   ├ CORE 加热高边 → 四200Ω → PWM低边
                                                   └ BASE_IO假负载门控 → 四200Ω
```

TPS22975：1/2 VIN和4 VBIAS接FUSED_5V，3 ON接MAIN_ON并100 kΩ下拉，5/EP接GND，6 CT接10 nF到GND，7/8 VOUT接5V_IN。芯片入口1 µF+100 nF；输出BASE端4×10 µF，CORE buck入口3×10 µF、CAN附近另10 µF。不要把未接到电容的另一只并联电源脚漏接。

供电合同：台架电源设5.1 V左右，**入口实测5.05～5.25 V、CORE的5V_IN保持4.75～5.25 V**，线损从上游补偿，不能把电源旋钮当板上电压。正常运行预算≤1.35 A，电源能力≥2 A，台架限流2 A；初次分段上电先低限流再提升。不能接机器人24 V电池，电机动力不流经本板；机器人电源需另有稳压/保护电源板，其板形也遵守40 mm上限。

| 负载/假设 | 预算 |
| --- | --- |
| MCU Direct SMPS输入 | 分配400 mA@3.3 V；是工程预留，并非ST保证的最大电流 |
| IMU/HSE/复位/小信号IO | 合计50 mA@3.3 V预留，包括三CAN VIO |
| AUX及全部扩展负载 | 合计500 mA@3.3 V设计上限，不是每接口500 mA |
| 3.3 V输入折算 | 0.95 A×3.465 V÷(4.75 V×80%)≈0.866 A |
| 三CAN VCC | 3×80 mA=240 mA，以50 Ω重载显性条件预算；60 Ω正常负载手册上限70 mA/路 |
| 加热全开 | 5.25 V÷49.5 Ω≈106 mA，约0.557 W；每电阻约0.139 W |
| 假负载全开 | 同上约106 mA；BASE_IO外接负载与板载50 Ω不能超预算叠加 |
| 5 V其他及余量 | 15 mA |
| 合计包络 | **1.333 A**；这是把各功能上限叠加的预算，不是实测典型值，也不表示同一BASE全部实装 |

若三路CAN都处于手册对应的110 mA故障条件，5 V包络约1.423 A；这只能用于估算供电承受能力，不能当作任意总线短路条件下的保证。AUX 500 mA必须扣除板载收发器/缓冲器/SD等用量，外接I²C等只能使用余量；TTL的电源针是参考，禁止外部电源反灌。

F1按连续75%降额，再暂按温度系数0.90预算：2.5×0.75×0.90=**1.688 A**，高于1.333 A。0.90是本项目保守预算假设，最终按保险附近实测温度和原厂曲线核定。原来的2 A在同样假设下只剩1.35 A，余量过小，因此升级2.5 A。2.5 A保险的典型冷阻28.6 mΩ、名义熔断I²t为1.029 A²s；不据此宣称短路立即断电。尤其2 A恒流源下保险可能长期不熔断，故障切除依靠源端保护/断电和支路保护，保险仅是后备。

铜箔按至少2 A连续的入口路径设计，六个5 V触点全接、地触点充分并联，禁止窄颈或只用一针输电；焊盘扇出与线宽按铜厚/温升复核。按80%效率包络，buck损耗可能约0.82 W；全开加热和通信叠加后40 mm核心的热量不能忽略。不能直接依据TPS62132“3 A”标签声称整板能长期输出3 A。

## 5. 启动浪涌及关断

TPS22975的CT用10 nF C0G，VIN=VBIAS=5 V时10～90%上升时间典型约16.98 ms，**不是保证的最短时间**。样机目标5V_IN的10～90%≥5 ms。TPS62132的SS由3.3 nF改为10 nF C0G，按`Css=tss×2.5µA/1.25V`得到典型5 ms；3.3 V完整上升段验收目标≥3 ms。先释放复位，再初始化通信和温控，禁止启动即满功率加热/假负载。

按每只X5R/X7R标称×1.10×1.15计算充电容量上包络，不用降额后的最小容量算浪涌。最重CORE＋BASE_IO：主开关后直接5 V电容约104.24 µF，入口开关前另约1.39 µF；主3.3 V节点约85.89 µF，AUX约38.58 µF。

- 主5 V斜率充电：`104.24µF×(0.8×5.25V)/5ms≈87.6mA`。
- MCU Direct SMPS启动输入不能只算外部电容；DS13312列有420 mA最大启动电流，另预算50 mA核心负载、AUX限流上界644 mA。AUX限流包络已包含它自己的充电，不能再次把AUX电容电流全额叠加。
- 主3.3 V容量按3 ms充电、再折算buck输入，叠加上述5 V充电与杂项，得到约**1.21 A启动预算**。这是简化包络，不能替代波形；VIN低于正常工作区时、UVLO重复启动及所有限流容差不由该算式保证。
- 验收暂定入口启动峰值≤1.6 A、主要启动过程≤30 ms，且无掉压复位/多次重启。矩形示例I²t为0.0768 A²s，约保险名义1.029 A²s的7.5%；保险名义数据基于8 ms，不能用这个比例直接认定重复脉冲寿命合格。

**输入热插拔与按开关启动是两种测试。**FUSED_5V的入口电容在软启动开关之前，插电时的尖峰和线束LC振铃不受CT控制；需在最长允许线束、源端低阻条件下测量，确认TPS22975端口不超过5.7 V推荐工作范围，超限则增加经验证的输入阻尼/钳位方案后再发布。不能随手加一只“5 V TVS”就认为钳位一定低于5.7 V。

关断测5V_IN、3V3_D、AUX、NRST、HEAT_ALLOW的时序；TPS22975快速放电并不等于所有节点立即归零。上游断电、AUX锁断、只接USB、连接通信另一端已上电等工况都要检查反灌。物理插拔J1/J2只能在断电后进行。

2026-10-17 实际布局复核：L301/L2 是 **XFL4020-222MEC，2.2 µH**，原厂最大高度为2.10 mm（[Coilcraft 图纸第3页](https://www.coilcraft.com/getmedia/50632d43-da1b-4cdb-8ab4-3029cab51df3/xfl4020.pdf)），加0.20 mm局部安装余量得到2.30 mm包络。最小间隙余量为6.32−2.30−1.80−0.50=**1.72 mm**。商城官方器件关联的封装/3D名称为XAL4030，不能以该名称替代实际BOM型号或据此确认三维高度；焊盘中心距2.3698 mm、约1.00×3.50 mm，原厂建议2.37 mm、0.98×3.40 mm，属略放大的兼容焊盘。真实三维模型与装配碰撞仍需复核。

定位柱孔只定位，不独立保证防反插；非对称固定孔必须配合先装隔柱/导向再插合，并保留J1/J2和Pin1标记。不能强压PCB使螺钉孔就位。固定孔允许在实际PCB阶段小范围修订，但**必须五块板一同修改同一机械基准**，不能各画各的。

CORE顶面：MCU中心约(23,19)，14×14 mm区域包含BGA逃线、内部SMPS电感和就地去耦；IMU/加热在左侧约(9,20)，远离底面buck与三CAN；USB朝右边缘，信号焊盘基准(32.445,19.9)，口沿X=39.8；SWD朝上可插拔，三个按钮在北边。三CAN电路在南侧，5 V buck在底面偏北，AUX/门控在底面偏右。不要在IMU正下方布buck开关环路、假负载或高电流回路，也不要切断USB/时钟参考地。

BASE顶面放SFM及低器件，**高XH/PH插座、开关、SPI/PWM接头都放朝外底面**。否则6.3 mm板间隙放不下插头和插拔动作。底面XH的通孔焊脚在顶面要单独避让SFM及IC；区域无重叠不代表这些穿孔细节已经验证。电源PH、SPI/PWM的SMT化是为消除板边与SFM相对位置的通孔干涉，不是任意换插头。

BASE_IO的microSD从西侧抽插，留卡片进退路径；电位器从底面调节。49个探测点分成北侧25、南侧24，1.27 mm间距、Ø0.8铜，中心Y=0.8/39.0，供拆开后的治具测量；不建议把高速线直接长引到示波器导线上。未增加49个排针。

尺寸目标是PCB平面外形，**不是插好线后整体包络40×40×若干mm**。两层PCB加间隙约9.55 mm，外侧器件与插头还会增加高度。预留底部插拔空间和线束弯曲/应力释放；机器人上的线束应固定在机架，避免拉力直接作用于小板和100个焊点。
