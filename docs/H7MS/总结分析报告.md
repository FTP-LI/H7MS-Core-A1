# H7MS-Core-A1 总结分析报告

2026-10-11 · Docs v0.8.0 · 原理图输入规划阶段

**当前选用 STM32H735VGH6（TFBGA100，0.8 mm 球距）+ Direct SMPS。**这是用户确认后的设计基线；电路、外围候选及引脚完成文档规划，尚未完成 EDA 原理图、PCB 或实物验证。

## 选用理由

三路独立原生 FDCAN 是硬要求，H735 兼顾紧凑封装、Cortex-M7 运算能力及内置 SMPS；本轮不用 H743 两路 CAN 替代。用户已有适合的 H735 采购渠道，公开平台的单次无库存记录不再作为否决理由。实际采购价、批次和交期尚未形成订单。

H735 比同封装 H723 多出 SMPS 电源相关球位，减少的 PE11～PE15 会影响部分扩展复用，但当前按达妙及此前 H723 功能范围编排后，**三 CAN、USB、IMU、四设备串口和 W25Q128 无引脚冲突**，还能保留 TF、四 PWM、SPI3、I²C、辅助串口及状态采样。没有为完整旧 H743 TIM1 互补输出组或以太网牺牲现有接口。

SMPS 带来的工程代价是一颗小电感、输入/输出电容和紧凑开关回路；降低内核供电损耗的价值需要整板温升验证。当前不按芯片面积直接估算整板面积，也不把“550 MHz”写成已经达到的板级性能。

| 类别 | 本轮规划 |

## 职责与板级边界

上位机负责整机状态融合、视觉、规划及应用算法。核心板负责带时间戳的采样、目标调度、设备通信、超时和故障处理，可运行轻量 AHRS。电流环/FOC 通常位于智能电机驱动器，不因选了 H7 就把所有环路搬到同一块主控。

核心板放 MCU、NOR、IMU、时钟、USB、TF 和低压电源；底板放三路 CAN、串口物理层、宽压输入、执行器配电与独立禁止回路。这样保留小核心，同时允许不同机器人选择不同接插件、隔离与功率等级。板间两组 50 位仅为逻辑分配草案，机械尺寸未冻结。
