# H7MS-Core-A1上下板接口规范

版本：Stack Interface v0.7  
状态：原理图输入基线，连接器料号和针序需经封装/机械复核后冻结  

适用范围更新（2026-09-15）：面向通用核心板与接口底板，逐Pin、电气规则及安全时序未改变。`SERVOx`是既有网络名，对应可配置设备串口；`COMPUTE`不绑定上位机型号。

## 1. 连接器与容量

采用两只50Pin、0.4 mm间距板对板连接器，候选配对：

- Core-A1：`DF40C-50DP-0.4V(51)`。
- 底板：`DF40HC(3.0)-50DS-0.4V(51)`，标称3.0 mm叠高。

每只连接器分配：26个信号、4个`BASE_5V`、2个`CORE_3V3_AUX`、12个地、6个预留。两只合计100个触点：

| 类型 | 数量 |
| --- | ---: |
| MCU/控制信号 | 52 |
| BASE_5V | 8 |
| CORE_3V3_AUX | 4 |
| GND/AGND回流 | 24 |
| Reserved | 12 |

`NRST`既是核心板固定调试信号，也占用一个J1信号触点，因此连接器有52个信号触点，而外部可用MCU资源为51个。

## 3. 电气规则

| 网络 | 规则 |
| --- | --- |
| BASE_5V | 底板输入到核心板；8触点并联；禁止给执行器供电 |
| CORE_3V3_AUX | 核心板输出；四触点并联；建议总限流200 mA |
| GND | 全部接公共地平面；靠近相邻信号建立回流 |
| AGND_SENSE | 底板模拟前端回流；最终在低阻地系统中连接，不是隔离地 |
| 数字输入 | 不得超过0～3.3V容限，除非具体引脚和保护电路另有验证 |
| ADC输入 | 底板输出0～3.3V，必须有RC和过压钳位 |
| RESERVED | A1保持NC，不允许底板私自用作电源 |

连接器单触点电流能力不能直接按触点数线性相加。A1以核心板5V持续输入不超过1.5 A为设计目标，并通过温升、压降和插拔老化实测确认。

## 4. 上电与安全时序

```text
底板产生BASE_5V
→ Core-A1复位并保持PWR_EN=0
→ 读取底板EEPROM/能力
→ 检查ESTOP_N与BASE_FAULT_N
→ 初始化物理层
→ PWR_EN=1
→ 等待PWR_GOOD=1
→ READY
```

- `PWR_EN`在核心板和底板都应有硬件下拉。
- `SERVOx_DIR`在底板下拉到接收/高阻。
- `CANx_STB`由底板设置成默认待机。
- `ESTOP_N`断线视为急停，不允许仅靠MCU判断切断功率。
- 底板拔出、任一连接器松动或PWR_GOOD消失时立即退出ACTIVE。

## 5. 底板类型建议

### 通用验证底板（名称待定）

- 提供5V转换、输入保护、监测、身份、安全握手及硬件禁止路径，明确允许输入范围。
- 提供串口物理层与CAN收发器/终端选件，标明电平、接插件、默认状态及互斥装配关系。
- 先完成一条串口和一条CAN真实链路，再按验证配置扩展端口和并发；接口引出不等于性能已验证。
- 引出采样、I/O与测试点，作为BSP、设备适配器和SDK的公共验证载板。

### 应用接口底板

- 按设备电压、线束、环境及节点分组选择串口、CAN、隔离与接插件。
- CAN采用匹配位率的收发器与可配置终端，按拓扑配置；经典CAN/FD兼容能力需逐项声明。
- 使用独立电机驱动器时，FOC、电流环、编码器与功率级在驱动端完成。
- 未用物理层可以不装，但不能改变针序、供电、默认状态或预留脚用途。

验证配置与能力声明见[通用需求基线](10_通用控制平台需求基线.md)。

## 6. 兼容纪律

- A1底板不得改变已定义Pin的电气方向和默认安全状态。
- 预留脚在Core-A1 A1版本保持NC；以后启用必须升级接口版本。
- 任意底板上电前必须能通过EEPROM报告`board_id、hw_revision、capabilities、power_budget`。
- 不兼容底板只能进入`SAFE_OFF`，不得尝试探测式驱动。

连接器正式冻结前需依据[Hirose DF40产品资料](https://www.hirose.com/en/product/p/CL0684-4014-0-51)复核额定电流、叠高、公差、耐久次数和配合方向。
