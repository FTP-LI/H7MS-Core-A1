# 引脚复用与应用配置

> 2026-10-13 补充：时钟/DMA、关键器件和 CORE/BASE-DBG 连接以 [v0.9.1 电气设计基线](时钟DMA与关键器件定版.md) 与 [连接设计](核心板与验证扩展板连接设计.md) 为准；下文未关闭项以该补充的状态更新。AUX 改为500 mA设计目标并增加限流及掉电隔离。
本表与[资源配置](资源配置.json)定义 v0.9 的可选组合。所有配置保留核心三 CAN、SPI4 BMI088、TIM1 加热、ADC3 温度/电源监测、一个 USB、时钟及 SWD。功能组可以重组，但组合后必须重新检查引脚、EXTI、定时器周期、时钟、DMA、缓存和底板接线，不能直接拼接配置名称。

## 固定资源与通用接口

28 个核心固定信号及 49 个扩展信号的球位见[归属表](77信号资源归属.csv)，完整连接见[100 球表](100球连接规划.csv)。核心必需项不提供运行中复用开关；变更它们要升硬件修订。扩展引脚允许按启动配置选择用途，配置生效前核对扩展板 ID/版本和装配信息，危险输出保持高阻并由扩展板下拉禁止。

新接口使用 `EXP_PA0` 这类焊盘名称。49 个引出不在核心预装 I2C 上拉、PWM下拉、串口反相、ADC 分压或存储负载；这些由具体扩展板按功能安装，避免旧功能的上下拉和分支悄悄限制复用。MCU 电气能力不等于接口耐压，GPIO/ADC默认只接 3.3 V 逻辑或 0～3.0 V 调理信号，5 V 兼容须逐脚、逐模式核查。

板间通信默认 UART4 或 SPI3；应用安全接口约定 PE10=PWR_EN、PA8=ESTOP_N、PB7=BASE_FAULT_N、PA10=PWR_GOOD。这些是扩展板配置契约，没有固定在核心外设上的负载；所列机器人配置均保留它们。若专用配置改作 I2C/PWM 等，必须重分配安全接口及扩展板硬件，不能只改固件。

## 应用配置与可同时使用的资源

| 配置 | 已检查的主要扩展资源 | 占用总信号 / 剩余扩展信号 | 用途与代价 |
| --- | --- | --- | --- |
| CORE_BRINGUP | 不启用应用 IO | 28 / 49 | 核心首上电、恢复、CAN/USB/IMU/加热验证 |
| RM_STANDARD | 4 个 TX/RX/DIR 设备口、UART7、UART8、SPI3+READY、I2C2、4-bit SD、4 PWM、2 ADC、安全 IO | 68 / 9 | 首发通用 RM；UART4 用于板间时只剩 3 个设备口给其他设备 |
| DUAL_SPI | RM_STANDARD 加 PA5 同步信号 | 69 / 8 | 同底板双 H735；外设配置并不自动赋予主从方向 |
| MEMORY_LOGGER | USART2/3、UART4+DIR、UART7/8、SPI3+READY、4-bit SD、Quad NOR、2 PWM、2 ADC、安全 IO | 65 / 12 | TF+NOR可同时规划；不含 I2C2 和原四组设备 DIR |
| NETWORK_GATEWAY | RMII+PHY控制、7 路 TTL 串口、SPI3+READY、4-bit SD、1 ADC、安全 IO | 70 / 7 | 三 CAN 仍保留；不含 Quad NOR、I2C2、PWM4；PHY待选 |
| SERIAL_IO | 9 路 TTL 串口、SPI3+READY、I2C2、TIM5 四 PWM、双 DAC、2 ADC、安全 IO | 65 / 12 | 无 SD/NOR；四个 PWM 共用 TIM5 周期；9 个方向控制脚未分配 |
| MOTOR_LAB | TIM8 三相互补/刹车、3 路 ADC1、TIM3 AB 编码器、USART2/3、UART4+DIR、UART7/8、I2C2、2 ADC3、安全 IO | 59 / 18 | 单轴裸电机功率板研究；不含 SPI3、SD、USART1；当前无控制算法/功率级验收 |

以上是物理引脚与 EXTI 可并存的组合，不是实测吞吐。端口数量表示已分配 TX/RX，不代表同时支持全部 Modbus、DBUS、RS-232、RS-485 等电气/协议；STM32 USART 同步 SPI 模式也不能再算一套独立外设。

## RM_STANDARD 的主要引脚

| 功能 | 信号分配 | 注意事项 |
| --- | --- | --- |
| 设备口 1 | USART1：PB14 TX、PB15 RX；PA0 DIR | 可用于裁判系统等 UART；按设备决定是否需要 DIR/电平转换 |
| 设备口 2 | USART2：PD5 TX、PD6 RX；PA1 DIR | DIR 为软件 GPIO，需 TC 后释放 |
| 设备口 3 | USART3：PD8 TX、PD9 RX；PD11 DIR | PD11 与 NOR IO0 互斥 |
| 设备口 4 | UART4：PD1 TX、PD0 RX；PD15 DIR | 线束板间 RS-485 优先占用该口 |
| 遥控/辅助 | UART7：PE8 TX、PE7 RX | DBUS/SBUS 的格式、反相与线电平分别核对；不把同一 RX 分给两个源 |
| 上位备用 | UART8：PE1 TX、PE0 RX | USB 和 UART 同时接上位时要有唯一控制权 |
| SPI3 | PB3 SCK、PB4 MISO、PB2 MOSI、PA15 NSS；PB1 READY | PB2 MOSI 的 AF 以生成表为准；主机 NSS 可用 GPIO，从机用 AF |
| I2C2 | PB10 SCL、PB11 SDA | 上拉在扩展板；不跨长线直接使用 |
| TF | PC8～PC11 D0～D3、PC12 CK、PD2 CMD；PA4 检测 | 检测轮询，无 EXTI；SD 是扩展板功能 |
| PWM A | PC6/TIM8_CH1、PC7/TIM8_CH2 | 同一 TIM8 周期，不能一条舵机 50 Hz、另一条独立 20 kHz |
| PWM B | PA2/TIM5_CH3、PA3/TIM5_CH4 | 同一 TIM5 周期；不同于 TIM8 的时基 |
| 模拟监测 | PC0/ADC3_INP10、PC1/ADC3_INP11 | 输入前端在扩展板，采样与核心 NTC/5V 共用 ADC3 转换调度 |
| 安全接口 | PE10使能、PA8急停、PB7故障、PA10电源好 | 默认禁能，硬件独立禁止不依赖 MCU 是否执行中断 |

详细球位、AF 数字和 EXTI 见[应用逐针表](应用配置引脚.csv)。不同外设的同号 EXTI 不能同时作为独立 GPIO 中断；本组使用 IMU 13/10、安全 8/7、READY 1，DUAL_SPI 再增加同步 5。

## 必须公开的复用冲突

| 资源冲突 | 影响 | 处理原则 |
| --- | --- | --- |
| PB5/PB6 固定 CAN2 | I2C1/I2C4 的部分时钟与 LPUART1 TX 被占；SPI3 不能用旧 PB5 MOSI | SPI3 改 PB2；LPUART1 无完整可用 TX，不列作扩展串口 |
| SPI4 PE2/PE5/PE6 和 PE3/PE4 固定 IMU | SPI4不可给扩展使用；USART10 TX/RX 不可用 | 统一九个其他串口为可选上限，不承诺第十路 |
| TIM1_CH1 固定加热 | TIM1 时基归温控所有 | 其他 TIM1 输出不当作独立 PWM；电机实验使用 TIM8 |
| PB3/PB4 为 SPI3 | 与 SWO/JTAG附加信号及部分编码器复用冲突 | SWD始终保留；SWO默认不可用；编码器配置明确关闭 SPI3 |
| SDMMC1 PC12/PD2 | 与 UART5 TX/RX 互斥 | SD 配置与九串口配置分开 |
| PC6/PC7/PC8 | USART6、TIM8 PWM 和 SD D0 的组合冲突 | 网络配置用 USART6+SD；电机配置用 TIM8、不接 SD；RM仅用PC6/7 PWM+PC8 SD |
| Quad NOR PB10/PB13/PA1/PA3/PD11/PB0 | 与 I2C2、RMII、部分 DIR/PWM/模拟信号互斥 | 用 MEMORY_LOGGER 独立配置，不把 NOR 默认焊核心 |
| RMII PA1/PA2/PC1/PA7/PC4/PC5/PB11/PB12/PB13 | 与 I2C2、部分 ADC、PWM、NOR/SPI2 互斥 | NETWORK_GATEWAY 有专用扩展板；完整 CAN/IMU/USB 保持 |
| PA4/PA5 DAC | 与 SD 检测、SYNC、TIM8互补输出等互斥 | SERIAL_IO 分配双 DAC；其他配置按需另审 |
| PE10 安全使能与 TIM1_CH2N、UART7_CTS | 固定应用安全契约占用功能 | 不因 CTS 或 PWM 需求取消独立禁止链路 |
| ADC1/ADC2 与 GPIO/ETH | 同一模拟焊盘不能同时承载数字输出 | 通道数按独立输入焊盘统计，不把 ADC1/2 共用脚计两次 |

板上可以预留 0 Ω 装配选项，但每个选项都要记录“装哪一组、另一组是否有残留负载、未上电是否反灌”。动态运行中切换总线必须先停输出和 DMA、隔离外部负载、切换 GPIO/外设并重新握手；首版只允许停机重启后选择配置。

## 常见机器人应用分配

| 应用 | 配置基础 | 任务和设备划分 |
| --- | --- | --- |
| 步兵/英雄等轮式平台 | RM_STANDARD | 按底盘、云台、发射划 CAN；先按实际电机协议核对控制 ID/反馈 ID 与帧率 |
| 哨兵/多执行机构 | 双板 RM_STANDARD 或 DUAL_SPI | 本地闭环按机械子系统分板；上位视觉/规划只产生有效目标 |
| 工程机器人/机械臂 | RM_STANDARD、SERIAL_IO、双板协作 | 智能关节走 CAN/串口；阀、舵机、编码器和限位装扩展前端 |
| 腿式/平衡机器人 | 双板协作，必要时 NETWORK_GATEWAY | 统一时基及目标生效时刻；全身状态反馈与控制往返单独测量，不保证500Hz板间足够 |
| 云台/稳定平台 | RM_STANDARD裁剪 | 核心本地 IMU 和温控；电机反馈与姿态环在同板，安装刚体/坐标明确 |
| 网络桥接/调试记录 | NETWORK_GATEWAY、MEMORY_LOGGER | 桥接限流，不让网络/写卡阻塞本地控制；需要同时网口和NOR时另配存储而非合并两表 |
| 采集与通用 IO | SERIAL_IO或专用ADC配置 | 前端保护、参考、滤波、通道切换和输出缓冲按传感器精度设计 |
| 单轴 FOC 研究 | MOTOR_LAB | TIM8互补、硬件刹车、ADC触发、编码器配套功率板；先低压负载试验 |

## 相对旧工程的迁移清单

应用算法、设备协议和 FreeRTOS 结构可以复用；H723/H735 的启动供电不能互抄。新版 BSP 必须重映射 CAN2 PB5/PB6、SPI4 IMU、两个片选/IRQ、PE9加热、全部扩展信号与安全输入；SPI3 MOSI 从 PB5 改 PB2。不要只把 SPI1 外设名替换成 SPI4 后遗漏 DMA request、IRQ优先级和时钟源。

旧核心 NOR/TF 的驱动变为扩展板能力；启动时未发现存储板时必须禁用对应任务/升级暂存路径。旧 J1/J2 触点不能与新表混用；必须给硬件 ABI、扩展板配置和校验文件分别编号。v0.8 文档和校验继续作为历史输入保留，新工程以本目录和 v0.9 JSON 为准。
