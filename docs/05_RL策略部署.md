# H7MS-Core-A1 RL策略部署

## 1. 定位

本篇为通用平台的可选算法扩展，不作为基础控制板发布前提。Core-A1运行已训练策略，不在MCU执行PPO、SAC等完整训练。训练、批量回放和优化器运行在外部开发计算机，GPU型号不属于控制板约束；H7按配置执行推理。

```text
MuJoCo / Isaac Sim
  └─ PPO/SAC训练（外部计算机）
       └─ 只导出Actor为ONNX
            └─ STM32Cube AI Studio分析/转换
                 └─ 生成C代码与权重
                      └─ H7回放验证
                           └─ 限制条件下真机部署
```

## 2. 可选推理基准模型

容量与时序评估保留一个纯MLP算例，实际模型需由应用定义。此例不固定平台节点数、关节数或控制周期：

```text
观测45维 → Linear 128 → ReLU/Tanh → Linear 128 → ReLU/Tanh → Linear 12
```

约2.4万个参数。FP32权重约96 KB，INT8约24 KB；目标运行频率为200 Hz。只有在实测推理时间、数值误差和控制效果满足要求后，才增大到256宽度或更复杂结构。

以上是容量量级估算，尚无模型文件或上板报告归档。三层均带偏置时共23,948个参数，FP32参数为95,792字节；INT8实际包还需计入偏置、量化比例和对齐等开销。模型参数大小不等于运行时RAM占用，Flash、激活工作区、任务栈与DMA缓冲应分别统计，见[主控选型与资源预算](07_主控选型与资源预算.md)。
## 3. 策略接口

策略输入必须固定顺序、单位和坐标系，例如：

- 12维关节位置。
- 12维关节速度。
- 3维机体角速度。
- 3维重力方向或姿态观测。
- 3维期望运动命令。
- 12维上一周期动作。

策略输出为归一化动作，不直接操作执行器。安全层依次完成：

1. 模型和观测时间戳校验。
2. NaN/Inf与范围检查。
3. 反归一化。
4. 关节软限位和动作变化率限制。
5. 姿态、温度、电源和通信约束。
6. 转换为位置、速度或力矩目标。

位置、速度、力矩/电流目标按设备适配器声明的能力选择；不支持的模式拒绝执行，电流与力矩转换需明确标定。模型的动作维度、设备映射、单位和兼容标识必须一致，不能根据总线类型推断控制模式。

## 4. 模型包

QSPI中的模型包至少包括：

| 字段 | 作用 |
| --- | --- |
| magic / format_version | 拒绝错误格式 |
| model_version | 模型追踪 |
| hardware_id | 限制可运行硬件 |
| observation_schema | 输入顺序、维度与单位 |
| action_schema | 输出顺序与控制模式 |
| control_period_us | 训练假设的运行周期 |
| normalization | mean/std或scale/offset |
| payload_length | 防止越界 |
| CRC32 / SHA-256 | 完整性检查 |

保留`current`和`fallback`两个槽位。新模型只有通过完整性、兼容性和回放测试后才能设为当前模型；启动失败回退到内部Flash中的安全控制器。

## 5. 内存放置

- 权重优先保存在内部Flash；容量不足时放QSPI，启动时映射或复制热点层。
- 输入、输出和小型工作区可放DTCM；普通外设DMA1/DMA2缓冲不能直接放入该区域，MDMA访问则需单独设计，详见[固件内存约束](02_固件架构.md)。
- 大型激活区和DMA共享缓冲放AXI SRAM并处理D-Cache一致性。
- TF卡不在实时推理路径中，只用于日志、轨迹和离线更新包。

## 6. 验证闸门

1. PC上保存一组固定观测及ONNX参考输出。
2. Cube AI生成代码后，在H7上逐样本运行。
3. 比较最大绝对误差、均方误差和动作符号。
4. 测量平均、P99和最大推理时间。
5. 同时开启IMU、执行器通信和日志，验证最坏时序。
6. 先回放和无动力故障注入，再进入受限设备台架；具体应用自行定义后续机械验证阶段。

此MLP算例的初始目标为200 Hz周期内推理最坏耗时≤2 ms、整个控制周期≤4 ms，并分别检查周期裕量及至少20%的CPU余量。这些不是平台通用合格线，最终阈值按应用负载与真实链路冻结。未加载模型时基础通信、安全与诊断仍须可用。

## 7. 不属于A1的范围

- MCU端完整PPO/SAC训练。
- 无安全边界的在线权重更新。
- 视觉神经网络与运动策略端到端运行。
- 由策略直接控制MOSFET、急停或电源使能。

允许的在线自适应仅限经过界定的小参数，例如IMU零偏、关节零位、摩擦补偿和动作缩放；它们必须有上下限、版本和恢复值。
