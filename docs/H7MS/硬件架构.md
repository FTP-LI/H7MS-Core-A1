# H7MS-Core-A1 硬件架构

2026-10-13，v0.9。完整架构图与电气边界见[核心板与扩展板总体规划](工程规划/核心板与扩展板总体规划.md)。

核心：H735VGH6、Direct SMPS、5V转3.3V、时钟/恢复、SPI4 BMI088、加热/温度/独立切断、三颗CAN收发器、一个USB FS Device。扩展：外部供电及执行器配电、CAN线束接口/终端、RS-485、SD/NOR、可选RMII与模拟/控制IO。

核心固定28个信号，49个灵活信号引出，23个电源/系统球位。三对CANH/L通过新板间接口传至扩展板；接口逻辑与机械/SI验收分开，编号不兼容v0.8。核心与扩展通过配置表确定复用，GPIO上的物理负载必须与所选功能一致。

绘图以[新版100球表](工程规划/100球连接规划.csv)、[100触点逻辑表](工程规划/板间100触点逻辑规划.csv)、[候选BOM](工程规划/外围资源与候选BOM.csv)及[分层原理图实施要求](工程规划/实施步骤与验收矩阵.md)为输入。旧最小系统文档仅保留电源/恢复参考，外设引脚和板级归属已更新。
