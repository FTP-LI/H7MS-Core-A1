# H7MS 设计入口

2026-10-17 R4B，当前原生核心原理图为11页、212器件、740引脚。四组UART与四GPIO排针在核心，另外7组UART分配到上层扩展；SPI1 IMU、直立USB/GH、XT30 12–48V电源已写入核心原理图。见[当前核验与预览](../../hardware/easyeda-pro/review-native/H735-review.html)。原生DRC仍须闭合；旧137器件PCB不适用于本次方案，扩展板及热岛PCB结构尚未完成。

所有板仍要求≤40×40mm。当前引脚、BOM和60触点板间接口以[R4B入口](../../hardware/easyeda-pro/review-native/H735-review.html)所列文件为准。下方v0.9文档保留历史设计依据；100触点、SPI4 IMU、旧布局和DMA分配不可直接沿用。

2026-10-13，Docs v0.9 draft。主控 STM32H735VGH6、0.8 mm TFBGA100、Direct SMPS。当前采用核心板与扩展板，核心必需三 CAN 收发器、SPI4 BMI088、IMU 加热和一个 USB FS Device。
