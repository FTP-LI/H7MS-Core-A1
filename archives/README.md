## 3. 校验与恢复

1. 对ZIP计算SHA-256，与同名`.sha256`第一列比较。PowerShell示例：

   ```powershell
   Get-FileHash -Algorithm SHA256 -LiteralPath './H7MS-Core-A1_2026-09-11_docs-v0.7.1.zip'
   ```

2. 解压到新的空目录，避免覆盖当前工作目录。ZIP以`H7MS-Core-A1/`为顶层目录。
3. 按包内`ARCHIVE-MANIFEST.json`的`files`列表核对源文件路径、长度和SHA-256。清单记录的是源文件，不把清单自身加入哈希列表。
4. 从解压后的README进入文档；先检查项目状态、未决问题和版本，再决定是否采纳历史内容。
