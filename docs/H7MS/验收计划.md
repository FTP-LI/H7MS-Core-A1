# 验收计划

状态均为待执行；现有脚本只验证文档与引脚数据。

| 阶段 | 方法 | 通过证据 |
| --- | --- | --- |
| 原理图输入 | ST球位/AF、100球覆盖、器件电压/封装、默认状态 | 静态校验记录及人工电源复核 |
| EDA | 正式原生工程、BOM、ERC；检查每个电源球和去耦 | 绑定硬件修订的图纸/PDF/ERC |
| 首上电 | 限流5V，先不接电机；量3.3V/VCORE/纹波/启动 | 示波器波形、电流、温升与反灌检查 |
| 恢复 | 正常复位、故意错误供电固件、BOOT0+POR+SWD恢复 | 可重复流程及option-byte记录 |
| 外设 | 三CAN各自回环/实总线，USB枚举、四UART、IMU、NOR、TF | 器件ID、读写校验、节点通信、USB断连重连 |
| 并发 | 明确帧长/周期/节点数/速率后，同时运行所有必需接口 | 时间戳、丢包/错误计数、CPU与各RAM峰值、最长调度延迟 |
| 故障 | 主机掉线、单路bus-off、存储忙/卡拔出、MCU卡死、底板断线 | 故障隔离、停止输出和恢复，无过期指令重新生效 |
| 电气/环境 | 输入上下限、启停/短路扰动、ESD、温升、振动与IMU温漂 | 对具体配置的实测限值；不按器件标称代替整板结果 |

需先制定的数值：目标控制周期/最大抖动、接口组合速率、节点数量、故障停止上限、温度范围和电源持续负载。用户尚未给定最终应用规模，这些项目保留为验证输入，不虚设为产品承诺。
