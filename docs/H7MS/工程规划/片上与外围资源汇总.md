# 片上与外围资源汇总

> 2026-10-16更新：本文件的BASE-DBG按逻辑全集保留；实际五板、39.8 mm外形、电源/机械/MLCC变更以[v0.9.3设计输入](电源机械与40mm布局定版.md)和[紧凑板连接表](紧凑板原理图连接.csv)为准。旧3.3 nF软启动、未定电容/开关、单块大验证板及LSE预留焊盘描述不再用于A1。

> 2026-10-13 补充：时钟/DMA、关键器件和 CORE/BASE-DBG 连接以 [v0.9.1 电气设计基线](时钟DMA与关键器件定版.md) 与 [连接设计](核心板与验证扩展板连接设计.md) 为准；下文未关闭项以该补充的状态更新。AUX 改为500 mA设计目标并增加限流及掉电隔离。
资源分为芯片内部能力、精确封装可达能力、核心固定占用和扩展板可用配置四层。H735 家族“最多”外设数不能直接变成 TFBGA100 本板接口数。以下依据[ST H735 产品资料](https://www.st.com/en/microcontrollers-microprocessors/stm32h735vg.html)、[本地精确封装 XML](../技术依据/compact-mcu-review/STM32H735VGHx.xml)、[完整引脚复用矩阵](封装全部复用矩阵.csv)及[应用配置](资源配置.json)。

## 计算和内存

| 片上资源 | 容量或能力 | 本项目分配原则 |
| --- | --- | --- |
| CPU | Cortex-M7，最高550 MHz，单核 | 先验证480 MHz；550 MHz按VOS、温度、Flash等待周期和系统时钟限制配置 |
| 算术 | 单/双精度FPU、DSP指令、CORDIC、FMAC | 控制、姿态和滤波；性能按算法实测，不跨架构只比MHz |
| Cache与保护 | 32 KiB I-cache、32 KiB D-cache、MPU | DMA一致性、缓冲所有权和内存属性须设计 |
| 片内Flash | 1 MiB，ECC，单Bank | 启动/应用/参数预算；擦写不能承诺不中断实时任务 |
| DTCM | 128 KiB | 控制关键数据/栈候选，不能假定一般DMA可达 |
| ITCM与AXI固定部分 | 64 KiB ITCM、128 KiB AXI | 热点代码与系统/DMA可访问数据按链接布局分配 |
| 可重分配内存 | 192 KiB在ITCM/AXI间配置 | 不重复计入容量；改分配需同步链接脚本与启动配置 |
| AHB SRAM | 合计48 KiB | 按所在域及DMA主设备可达性划分，不当作连续通用池 |
| Backup SRAM | 4 KiB | 少量故障/状态；依赖备份供电，不作为主控制工作区 |
| 总RAM | 560 KiB非备份 + 4 KiB备份 | Cache不计入可供应用分配的RAM；外部NOR不计RAM |
| DMA | DMA1、DMA2、BDMA、MDMA及相关请求路由 | DMA1/2各8个stream；哪些外设可接BDMA/MDMA需核实，不能总量简单相加 |
| 总线与ECC监测 | AXI/AHB矩阵、RAMECC | 区分算力不足、总线争用、不可达缓冲与ECC异常 |

初始内存预算以链接map为准：控制/状态与栈、通信DMA、CAN软件队列、USB、IMU、TF/NOR/网络缓存分别建账。先为板间通信划定约8 KiB可达非缓存区域，日志使用有界环形缓冲；联网配置单独预算网络缓冲，不在无网配置里常驻分配全部网络内存。

## 全部通信外设类别

| 芯片资源 | 精确封装及本板可用情况 | 当前用途/限制 |
| --- | --- | --- |
| FDCAN1/2/3 | 3路独立控制器，均固定核心 | 三颗收发器；消息RAM容量/偏移由所有实例联合规划，不将整块RAM重复分配 |
| USB OTG HS 控制器及内置FS PHY | 核心固定1个FS数据口 | Device，12 Mbit/s；无外置ULPI PHY，未实现480 Mbit/s、Host供电或第二USB口；XML别名不算双控制器 |
| USART1/2/3/6/10 | 5个实例；USART10引脚被SPI4/IMU片选固定占用 | 其余4个可在SERIAL_IO中完整引出 |
| UART4/5/7/8/9 | 5个实例 | 可与上述4个USART在SERIAL_IO中组成9个TX/RX口；UART5与SD冲突 |
| LPUART1 | 封装有信号，但TX候选PB6/PA9分别被CAN2/VBUS占用 | 当前核心不提供完整LPUART扩展口，不计作第十路 |
| SPI1/2/3/4/6 | 精确封装XML有这5个实例的引脚，未见SPI5引出 | SPI4固定IMU；SPI1/2/3/6为复用候选，SPI3/6共享很多脚，不能声称另有4路可同时用 |
| I2C1/2/3/4/5 | 家族5个；当前固定CAN使I2C1/4完整时钟路径受限 | 默认I2C2；I2C3/5需按安全IO/SD等重排，不承诺三组默认同时可用 |
| OCTOSPI1/2与OCTOSPIM | 内部两个实例，TFBGA100候选信号集中于Port1 | 已核一套Port1 Quad NOR配置；不承诺两个八线接口或HyperBus完整引出 |
| SDMMC1/2 | 两个实例 | SDMMC1四线配置已核；SDMMC2的部分脚与固定CAN STB/USART1等冲突，未形成完整第二卡口配置 |
| ETH MAC及专用DMA | RMII完整引脚配置已核 | 需扩展板PHY、时钟、磁性器件和接口保护；目标10/100M，实际吞吐/时延待测 |
| SAI1/SAI4 | 音频串行外设 | 候选复用功能，按时钟/数据脚另审；无核心音频编解码器 |
| I2S1/2/3/6 | 与对应SPI复用 | 不是额外四条独立SPI/I2S总线 |
| SPDIFRX1 | 数字音频接收 | 无核心光/同轴物理前端；按需扩展 |
| HDMI-CEC | 单线控制外设 | 无HDMI视频输出能力承诺，需独立电气前端 |
| SWPMI1 | 单线协议接口 | 仅候选资源，未列首发应用 |
| MDIOS | MDIO从接口 | 与Ethernet MAC的管理接口用途分开，不算第二网口 |
| DCMI/PSSI | 相机/并行从接口，共享部分硬件/引脚 | 完整总线与核心固定脚、存储/网络冲突较多，未冻结成应用配置 |

所有精确信号与复用号都在932行[AF矩阵](封装全部复用矩阵.csv)。有些XML条目是USB_DEVICE、FreeRTOS、FATFS、LwIP等中间件，不能计入芯片物理外设；[XML索引](芯片XML资源索引.csv)保留它们用于追溯。

## 定时器与控制资源

| 类别 | 实例 | 分配与可用条件 |
| --- | --- | --- |
| 高级16位定时器 | TIM1、TIM8 | TIM1时基归IMU加热；TIM8支持另行配置互补输出/死区/刹车，MOTOR_LAB已核信号组合 |
| 通用32位定时器 | TIM2、TIM5、TIM23、TIM24 | TIM5用于部分PWM配置；另选空闲实例作微秒时基。内部定时能力不等于每个实例都有本封装四通道输出 |
| 其他16位定时器 | TIM3、TIM4、TIM6、TIM7、TIM12～17 | TIM3编码器已核；TIM6/7主要内部时基/DAC触发，不当作外部PWM；其余按实际信号选择 |
| 低功耗定时器 | LPTIM1～5 | 低速定时/唤醒候选，按时钟域和外部脚检查 |
| 看门狗 | IWDG1、WWDG1 | 多任务健康汇总后喂狗，具体VOS/电压限制按勘误处理 |
| SysTick | 1个 | RTOS或系统节拍，精密控制不只依赖tick唤醒 |

厂商“24个定时器”包含17个16位（其中5个LPTIM）、4个32位、2个看门狗和1个SysTick；不能理解为24组四通道PWM。RM_STANDARD的4个PWM分属TIM8与TIM5两组周期，SERIAL_IO的4个PWM同属TIM5一个周期。

## 模拟和传感资源

| 资源 | 数量/封装可达输入 | 当前占用与扩展 |
| --- | --- | --- |
| ADC1 | 16位；精确XML有14个外部单端INP信号焊盘 | 14个都可从灵活接口选择，但与数字外设互斥；MOTOR_LAB选择PA0/PA1/PA2 |
| ADC2 | 16位；精确XML有12个外部单端INP信号焊盘 | 与ADC1的焊盘大量重合；不能把14+12当26根独立模拟输入 |
| ADC3 | 12位；精确XML有PC0、PC1、PC2_C、PC3_C四个外部单端输入 | PC2_C/PC3_C固定5V监测/NTC；PC0/PC1扩展；内部温度/VREF等另算 |
| DAC1双通道 | 2×12位，PA4/PA5 | SERIAL_IO双输出；精度、输出范围、驱动能力和缓冲由模拟前端保证 |
| COMP1/2 | 2个比较器 | 外部脚与ADC/GPIO冲突；独立过温禁止不能仅依赖由同一MCU固件配置的比较器 |
| OPAMP1/2 | 2个运放 | 候选输入/输出脚部分与固定加热或其他功能冲突，不计作两个已接好的仪表放大器 |
| DFSDM1 | 8通道/4滤波器的内部能力 | 需要外部ΣΔ调制器和完整引脚配置；不等于8路板载ADC |
| DTS/VREFINT/VREFBUF | 温度/参考相关内部资源 | 用于芯片热管理/校准；参考输出与外部VREF不能争用，按所选供电配置 |

上述ADC统计排除了EXTI触发项和INN负端，按单端输入信号统计。独立扩展模拟输入焊盘并集为14个；采用全模拟配置时需放弃相应串口、PWM、SPI或网络功能。ADC3核心温控测量的采样率、采样时间和输入阻抗要独立保证。

## 系统及其他片上资源

| 类别 | 资源 | 工程处理 |
| --- | --- | --- |
| 存储控制 | FMC | 支持多种外存的内部能力；完整数据/控制引脚受固定功能约束，当前不承诺并行RAM配置 |
| 图形 | LTDC、DMA2D | 无核心显示接口；并行显示占大量脚，优先外部智能屏/上位机；不能把DMA2D当通用第二CPU |
| 安全/校验 | CRYP、HASH、RNG、CRC、OTFDEC1/2、唯一ID、读保护/防篡改 | 可用于镜像/配置校验及设备识别；加密能力本身不等于安全启动已实现 |
| RTC/备份 | RTC、备份寄存器、备份SRAM、VBAT | 首版VBAT接3.3V，选装备份电源需防反充；LSE占位保留 |
| 时钟 | RCC、PLL、HSE/HSI/CSI/HSI48/LSI/LSE | 统一时钟方案服务USB、CAN、SPI、UART和ADC；各外设内核时钟不等于CPU时钟 |
| 电源 | 内置SMPS/LDO、PWR、BOR/POR/PVD、低功耗模式 | Direct SMPS配置锁定及POR恢复；运行中频繁休眠不作为首版机器人模式 |
| 中断 | NVIC、GPIO EXTI与内部事件 | 每个GPIO EXTI编号只选一个端口来源；不可把同号PCx/PEx当两根独立IRQ |
| 调试 | SWD、JTAG/Trace能力 | 核心保留SWD/NRST/BOOT0；完整JTAG/Trace与SPI等冲突，不作为默认接口 |

## 对外资源总结口径

核心板可规划声明：H735VGH6、三路独立CAN FD物理接口、BMI088及加热硬件、一个USB FS Device、可靠供电/恢复、49个可复用信号引出。扩展能力按配置列出：RM通用组合、四线SD+Quad NOR组合、RMII网络组合、九路TTL串口组合或单轴电机控制实验组合。

资源上限不能跨表相加；所有外围仍处于选型/设计阶段，不是已生产BOM。完整生成数据和[验证结果](validation.json)提供可追溯的引脚证据；真实速率、并发、控制性能和电气可靠性由下一阶段试验确认。
