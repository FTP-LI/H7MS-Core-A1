## 时钟与DMA规划

先建立480 MHz基础档，550 MHz作为独立性能档。核查Direct SMPS、VOS、PLL输入/VCO/分频、Flash等待周期、AHB/APB和外设内核最大频率。USB取得合规48 MHz；CAN用适合位时序的内核时钟；ADC满足精度/采样时间限制；SPI4频率服从BMI088；串口3/6 Mbaud必须计算实际误差和过采样裕量。

| 数据路径 | 初始处理方式 | 要关闭的资源问题 |
| --- | --- | --- |
| BMI088 SPI4 | 中断时间戳 + SPI DMA或短事务中断 | TX/RX请求映射、双CS事务边界、优先级、缓冲可达性；不能把两个IRQ当同步采样保证 |
| 板间SPI3 | 双缓冲DMA、NSS+READY状态机 | 主从角色、DMA重装、欠载/溢出、缓存、半帧恢复及适用SPI勘误 |
| 板间UART4 | RX DMA环形缓冲、TX DMA或中断、TC控制DIR | 接收边界、环形缓冲溢出、RS-485方向切换、对端失联 |
| 其余UART | 高频接收优先DMA，低频TX可中断 | 同时六/九路串口不能机械地每个都占TX/RX各一条DMA stream |
| ADC3温控/监测 | 低频周期扫描，DMA或中断按资源选择 | NTC与电源采样阻抗、通道切换、最长失采样时间 |
| 三FDCAN | 硬件FIFO+有界ISR+软件快照 | 消息RAM实例分区、FIFO深度、过滤器、时间戳；不凭平均负载推断无丢帧 |
| SDMMC/ETH/USB | 各自控制器的数据路径与缓冲 | 按控制器DMA/IDMA和总线可达性规划，不能都按DMA1/2普通stream计数 |
| NOR/日志 | 低优先级分块事务 | 擦写繁忙、总线占用、可暂停队列，不阻塞控制 |

DMA1/2合计16个stream，但外设请求路由和BDMA/MDMA能力并非任意互换。例：六个串口全双向DMA占12条，再加SPI3/4各2条已到16条，尚未计其他普通DMA需求。该算术提示要改变传输方式、限制配置或验证其他可达引擎，不意味着所有外设都必须使用这种分配。

固定一张时钟、外设实例、引脚、DMA request/stream、IRQ优先级、缓冲区域、带宽和所有者表；.ioc和人工审查都通过才冻结。DMA区域保证对齐与cache一致性，控制关键数据和栈另放适当TCM/SRAM。勘误按DBGMCU芯片修订、CubeH7版本逐项判定适用性，不能只记录“已看勘误”。

## PCB与器件关闭清单

电感、MLCC、MOS和连接器先锁精确MPN及温度降额；USB-C、CAN连接器和堆叠连接器同时提交封装实物尺寸，不能只用第三方库自动导入结果。VGH6球位由原厂表和本目录CSV交叉审查，模块旋转、视图方向、Pin1和底视/顶视明确。

六层候选叠层至少提供连续信号参考地和合理电源回流，最终铜厚/介质/阻抗由板厂给出；不要把电源层切割后仍当作连续高速参考。USB差分、RMII、SD/Quad-SPI短连接优先，跨连接器的高速信号插入地参考并避免测试长支线。

IMU热岛、温度传感器、热源和独立切断器件需联合摆件；CAN收发器及SMPS远离敏感区域。热试验同时运行CPU、CAN、USB和加热，比较不同负载下的IMU温度梯度/偏置。检查USB插拔和堆叠应力是否传到IMU，连接器固定不只依靠焊点。

现有3V3_AUX外供是受限服务电源，扩展板大电流负载独立规划；参考地、屏蔽地、保护回流和执行器电流回流分别设计。电机再生能量处理位于具体功率/配电板，不由核心5V稳压器吸收。

## 固件工程结构与调度

首个可构建工程包含启动/Direct SMPS、时钟、MPU/cache、板级引脚、各驱动、时间服务、设备适配、控制、协议、故障、日志和配置层。统一源码按板型/角色选择BSP，不复制多个逐渐分叉的整套工程。固件必须知道所选应用配置，编译或启动时拒绝接口重复所有权。

本地控制和IMU采样独立于板间通信任务，网络/USB/TF/NOR均不能在控制任务或ISR中等待。中断仅搬运、时间戳与通知；调用RTOS API的IRQ优先级满足端口规则。看门狗只在关键任务更新健康计数后喂，不能让一个空闲线程掩盖控制任务卡死。

协议状态包含BOOT/DISARMED/READY/ARMED/FAULT；目标必须通过会话、序号、长度、CRC、量纲/范围及期限检查。掉线后的动作按底盘、云台、重力关节分别定义；核心CAN待机、停止发帧、零力矩指令和扩展板硬件禁能分别测量。

带存储配置才开启日志/OTA暂存。首轮先完成调试器下载、坏固件恢复和本地可靠配置，再做独立Bootloader；旧OTA的NOR分区只是容量预算，迁移到扩展板后需要验证缺板、掉电和通信中断场景。

首轮量化候选：本地控制1kHz，最大启动偏差50µs，计算与提交500µs内；3Mbaud串口500Hz板间交换，每方向128字节帧，完整事务1.5ms内；双板目标应用偏差50µs内。它们是测试目标，特定机器人可要求更严。台架初始目标TTL为10ms，超时后一个控制周期内提出禁止/降级；真实停止时间还受CAN排队、电机协议和机构影响，必须分开定义。

连续双板试验至少10⁷事务，500Hz约5.56小时，覆盖多次32位微秒时间回绕。记录最大值和P99/P99.9，正常台架出现无法解释的CRC错、FIFO溢出或控制超期就不能标记通过。对实际电机的首次故障试验先在限能量工装上做，之后逐步增加负载。
