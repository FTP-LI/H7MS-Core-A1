# H7MS-XGOBase-A1与接管

> **历史应用参考（2026-09-15退出当前范围）。**以下保留旧专用底板与接管方案用于追溯，其中“首版”“必须”等措辞仅适用于历史方案，不作为H7MS通用平台的需求、阶段或验收前提。当前方向见[通用需求基线](10_通用控制平台需求基线.md)与[README](../README.md)。

## 1. 底板目标

`H7MS-XGOBase-A1`不是原厂板的盲目复刻，而是把XGO专有电气接口适配到`H7MS-Core-A1`，并提供可验证的安全和测量能力。

首版必须实现：

- 至少一路可配置半双工舵机总线。
- 原厂线束转接和物理发送者互斥。
- 电池电压、电流与执行器电源状态。
- 急停、故障和执行器电源使能。
- 底板EEPROM、测试点和备用舵机接口。

四腿独立总线、机械臂第五总线和更换原装充电/BMS均属于实测后的可选项。

## 2. 投板前必须回答的问题

| 问题 | 验证方法 |
| --- | --- |
| 舵机信号电平 | 示波器高阻测量 |
| 半双工物理层 | 监听收发方向和空闲电平 |
| 波特率与帧格式 | 逻辑分析仪解码 |
| 总线拓扑 | 线束通断和拆机照片 |
| 舵机ID | 原厂单关节命令对应 |
| 状态字段 | 已知动作与返回帧关联 |
| 峰值电流 | 电流探头或分流测量 |
| 欠压行为 | 可控电源低速台架测试 |
| 原装保护 | 原理图、器件识别和故障测试 |

## 3. 协议逆向纪律

- 第一阶段只监听，不注入。
- 先识别读命令，再识别停止/卸载，最后才测试位置写入。
- 所有未知写操作只在备用舵机和限流电源上进行。
- 写入EEPROM、ID、PID、限位和固件的命令默认禁止。
- 原始抓包、注释和解析器版本一并保存，避免依靠人工记忆。

## 4. 线束与互斥

推荐使用可恢复转接线：

```text
               ┌─ 原装下位机
舵机总线 ── 物理选择/跳帽
               └─ H7MS-XGOBase-A1
```

首版优先采用断开式跳帽、锁定连接器或明确的机械选择，不依赖两个控制器的软件约定避免争用。选择器切换时执行器电源必须关闭。

## 5. 台架顺序

```text
空载收发器波形
→ 备用舵机只读
→ 小角度位置命令
→ 停止与卸载
→ 连续读写和温升
→ 单腿悬空
→ 四腿悬空
→ 支撑架站立
→ 地面低速
→ 机械臂与夹爪
```

每一级记录供电、电流、波形、周期、错误数和故障恢复。任何失控输出都退回备用舵机阶段。

## 6. 与原厂链一致性

选择固定关节目标和动作序列，对比：

- 原厂发送目标与H7发送目标。
- 关节响应时间、超调、最终误差和重复性。
- IMU姿态、身体高度和足端位置。
- 上位机断联、执行器离线、急停和欠压行为。
- 长时间运行温升和通信错误。

只有Core-A1控制链在安全性不下降、时序和可观测性提高的前提下，才允许用于策略部署。

## 7. 后续版本

- A1：原厂舵机与电源适配，强调安全接管。
- A2：根据实测决定四腿独立总线、机械臂独立总线和更高精度电源监测。
- B系列：只有更换为开放关节驱动时，才引入CAN-FD、阻抗或力矩控制，不让A1承担不存在的需求。
