# H7MS-Core-A1 总结分析报告

2026-10-13，Docs v0.9 draft，工程规划阶段。

当前保留 STM32H735VGH6 和 Direct SMPS，核心板必需三路 CAN 控制器及收发器、BMI088、IMU 加热与独立过温禁止、一路 USB FS Device、时钟/电源/恢复。TF、NOR、串口物理层、网络、状态显示和执行器配电由扩展板按应用提供。

新规划将 IMU 改为 SPI4，CAN2 改 PB5/PB6，加热改 PE9/TIM1_CH1。这样在固定核心功能之外保留49个灵活信号，并已静态检查七套配置：核心调试、RM通用、双板SPI、存储记录、网络网关、串口IO、电机控制实验。应用上限不能跨配置累加。

多MCU优先两块同型核心：不同部位使用RS-485，同底板使用SPI3；本地采样/闭环和独立超时始终由各板承担。核心完整CAN接口有利于统一使用，但并不自动提供电气隔离或冗余容错。

完整结论、取舍与下一步见[总体规划](工程规划/核心板与扩展板总体规划.md)、[引脚配置](工程规划/引脚复用与应用配置.md)、[资源总表](工程规划/片上与外围资源汇总.md)及[实施验收](工程规划/实施步骤与验收矩阵.md)。旧v0.8数据保留为历史，正式工程不能混用旧J1/J2、旧SPI1 IMU或旧核心存储连接。

目前只有设计规划和静态证据，没有正式EDA/ERC、PCB、CubeMX时钟/DMA资格验证或实物性能结果。
