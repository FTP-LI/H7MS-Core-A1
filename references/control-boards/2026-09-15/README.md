## 方法和可追溯性

1. 先确认官方产品/发布者入口，再取得原始PDF、ZIP或用户DXF。A型原理图的第三方来源单独标识，不与官方直取文件混同。
2. 保存下载链接、时间、文件大小、SHA-256；厂商仓库与镜像另记录提交/Git blob。哈希证明副本一致性，不证明设计已验证或厂商签名。
3. 对全部原理图渲染并目视检查，结合器件厂商数据手册辨别控制器、物理层、连接器和存储单位；按PDF实际页数定位。
4. 原始资料、派生预览、研究结论分开保存。单板source-index.json列出每个资料文件；各ZIP清单还包含评估与入口文件。
5. 条件性电路风险与已证实物料/连线分别记录。没有实物、PCB及BOM时，不把图纸审查写成性能或生产验收。

`review/`保留抓取计划、下载记录、公开仓库元数据和索引/渲染/打包脚本。它是调研工作记录，不是H7MS固件。用户手册仅生成封面预览及全文文本；原理图及官方位号图逐页生成预览。DXF导出可能存在文字重叠，提取文本也可能丢失字符或阅读顺序，应回看图形。

渲染工具：Python 3.12、ezdxf 1.4.4、PyMuPDF 1.28.2；PDF约130 dpi，DXF约190 dpi。[处理说明](review/README.md)记录复现方式。原理图版本、日期与板卡销售版本可能不同，不推断库存或现售修订。
