# 达妙DM-MC02（H723）控制板评估

日期：2026-09-15。**四者中，DM-MC02最适合作为“多总线通用实时控制”的资源参考：3路片内FDCAN、2路RS-485、IMU、USB及外部Flash，LQFP封装也便于探测和返修。**其资源配置不直接等于H7MS的最终需求，实际并发和保护性能仍需测试。

## 2. 硬件资源

| 模块 | 观察/规格 | 定位和意义 |
| --- | --- | --- |
| 主控 | STM32H723VGT6，LQFP100；最高550 MHz、1 MB Flash、564 KB RAM | 原理图P1；24 MHz晶体。RAM总量包含不同区域及备份RAM |
| CAN | 3路片内FDCAN，对应3套物理接口 | P1、P4；有终端/保护器件，不能把芯片位率直接作为长线系统可用速率 |
| RS-485 | 2路，USART2/USART3及方向控制 | P4；手册“最高10 Mbps”描述转换芯片能力，完整链路还受布线/线长/节点限制 |
| PWM | 4路输出，来自TIM2和TIM1 | P1、P3；通道共用定时器时间基，不代表4个任意独立周期 |
| IMU | BMI088，SPI2、独立片选和中断；MOSFET控制电阻加热 | P2；加热供电接VCC_IN，设计须按输入最高值限制功率，不能套用固定5V方案 |
| 存储 | W25Q64JV外部NOR，容量8 MB | P1；不是8 Mbit，也不是工作RAM |
| 上位/调试 | USB-C、UART接口、SWD、启动/复位；另有板间扩展串口 | P1、P2、P6；按引脚表区分外接接口与扩展资源 |
| 配电 | 系统逻辑电源、可控外设5V、两路PMOS输出及电压采样 | P3、P6和手册；手册外设5V总输出2A、PMOS每路5A是厂商规定，不是本次测得 |
| 显示/采集扩展 | DCMI摄像头连接、LCD/SPI/I²C及对应供电 | P5、P6；占用引脚与RAM，按应用启用 |
| 网络/TF | 本次图纸未见以太网PHY或TF插槽 | H723芯片具备相关外设，不代表板卡已实现对应端口 |

主控和3路FDCAN依据[ST H723数据手册](https://www.st.com/resource/en/datasheet/stm32h723vg.pdf)。NOR容量依据[Winbond W25Q64JV](https://www.winbond.com/hq/product/code-storage-flash/qspi-nor/w25q-jv/?__locale=en&partNo=W25Q64JVSFAM)。

## 3. 文档差异与待核实项目

| 项目 | 证据 | 本次判断 |
| --- | --- | --- |
| 外部Flash单位 | 手册参数表写`8Mb`；器件W25Q64JV为64 Mbit；同手册第15节写`8Mbytes` | 按器件及详细章节记录8 MB，保留参数表单位不一致的说明 |
| 电压边界 | 手册同时写12～24V与“支持6S” | 6串常见4.2V满充锂电池为25.2V，超过24V字面上限；需厂商确认最大持续输入和瞬态条件，不能自行扩展额定值 |
| 反接/缓启动 | 手册声明具备，6页原理图未完整展示可追溯的输入保护链路 | 记录为厂商声明；复制设计前需取得相应版本详细电路及BOM |
| 原理图/手册年代 | 图纸2024，手册2025 | 引脚、电源及选件以具体购入/参考板版本重新核对，避免混用 |
| 停止功能 | 有电源控制、方向控制及软件资源 | 不等于已证明独立硬件急停、MCU挂死时输出禁止或驱动器STO |

## 4. 对H7MS的价值与代价

**3路片内CAN是H723相对当前H743方案的明确选型理由。**三个设备网络可分别用于不同节点组或流量/故障分区，但“是否需要第三路”应由节点拓扑决定。H743只有2路FDCAN，拥有更大的片内Flash/RAM；不能只比较550 MHz与480 MHz。

2路RS-485说明通用设备接入值得预留差分串口物理层。不过TTL、RS-485、半双工单线和设备协议不同，H7MS应通过底板选件和设备适配器明确组合，而非把所有串口统一接成一种电路。

LQFP100对初次硬件调试、探测和返修友好，代价是占板尺寸增加。其封装、AF分配和时钟与H7MS的H743VIH6基线不同；切换需要重新完成引脚、BOM、机械和供电复核。

## 5. 评价与验证重点

**评价：优先作为通信资源与开发便利性的参考；在三条独立CAN确有需求时，把H723列为认真比较的候选。**显示/摄像头、PMOS大电流输出和恒温均按目标场景决定，不全部进入H7MS核心板。

采用前应测试3CAN＋2RS-485＋USB＋IMU的混合负载，记录CPU、每区RAM、队列峰值、最大延迟和错误恢复；验证外设5V共享预算、PMOS温升、输入边界、加热失控及掉电/复位默认状态。本次未获取相应实测数据，也未对价格或当前批次供货作比较。
