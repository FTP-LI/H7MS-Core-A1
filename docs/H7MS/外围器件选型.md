# 外围器件选型

## 尚未闭合的物料项

MLCC的有效容量/ESR、LSE晶体及负载电容、NTC曲线、加热MOS及过温禁止、CAN TVS/CMC、RGB缓冲/LED、蜂鸣器、插座机械料号仍需正式选料。所有DNP功能保留引脚；采购和样机验证后再发布带唯一MPN的生产BOM。没有把旧参考板元件视作自动可替换料。

来源见[外围器件来源清单](技术依据/外围器件/README.md)，电源核心依据[AN5419](https://www.st.com/resource/en/application_note/dm00663674.pdf)。
