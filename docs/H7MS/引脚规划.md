# STM32H735VGH6 引脚规划

日期：2026-10-11。Pin Plan v0.8，规划草案。使用 **TFBGA100、8 × 8 mm、0.8 mm 球距**，按精确 H735 球位建立，不能套用 H723/H743 的 BGA 焊盘图。

## 当前资源

三路独立 FDCAN、USB FS Device、SPI1 BMI088、四组设备 UART TX/RX/DIR、Quad W25Q128 同时保留；另保留 UART8 上位备用、UART7 辅助、4 路 PWM、SPI3、I²C2、4-bit TF、4 路模拟采样、加热、RGB、蜂鸣器及电源/故障信号。仿照 DM-MC02 的功能组织，不是插座或引脚兼容复制。

75 个已分配信号焊盘包含时钟及专用模拟焊盘；另外 PB1/K5、PE10/H6 预留，23 个电源/系统球位单列。该口径不是“75 个普通 GPIO”。

## 并发限制

1. USB 使用 USB_OTG_HS 控制器的内置 FS PHY，12 Mbit/s；PA11/PA12 已占用。未配置 ULPI、480 Mbit/s USB 或 USB Host 供电。
2. 前三路 PWM 同属 TIM2，**共用周期**；第四路是 TIM1_CH1。没有承诺完整 TIM1 互补输出、刹车、DCMI、RMII 或第四路原生 CAN。
3. SPI3 MOSI PB5 是 **AF7**，不是其余 SPI3 引脚的 AF6；PB0 上的 NOR IO1 是 **AF4**。PB3 用作 SPI3 SCK，因此 SWO 不引出；SWD 保留。
4. PC4/PC5 用于 IMU 中断；TF 检测 PE5 用轮询，不能再占 EXTI5。当前 EXTI3/4/5/6/9 无重复。
5. 四路设备串口的 DIR 由 GPIO 软件控制；UART 外设名字与产品端口编号分开。UART7 复用 SBUS 时需按协议配置反相/格式，接口仍是 3.3 V 逻辑。
6. HSE 为 8 MHz 有源旁路，PH1 保留不接；LSE 可选装。可选功能不装器件时，仍保留引脚，不自动拿去复用。
7. ST XML 静态检查不覆盖内核时钟、DMA、缓存、USB 电气或时序。后续 CubeMX 和硬件验证仍是必要步骤。
