# 原生工程历史快照

本目录完整保留设计、封装修正、库检查和布局期间的原生导出，以便追溯或恢复。

**继续设计请从上一级 [H7MS-H735-R4B.epro](../H7MS-H735-R4B.epro) 开始。** 本目录中 `final`、`reviewed`、`verified` 等后缀只描述当时的阶段，不能取代当前版本索引。

- `before-*`、`original`、`empty-*`：操作前恢复点。
- `official-library-inspection*`：器件库检查用工程快照。
- `compact*`、`placement*`、`functional-layout*`、旧 `.epro2`：旧原理图/137 器件 PCB 阶段。
- `R4B*`：当前方案形成过程中的检查与交付快照；以当前主工程和其 SHA-256 为最终识别依据。

历史快照未重新设计或覆盖。原有记录中的本机路径、窗口标识用于追溯，在其他电脑上不代表可直接运行的编辑器连接。
