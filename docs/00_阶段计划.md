# H7MS-Core-A1阶段计划

更新：2026-09-15。以[通用平台需求](10_通用控制平台需求基线.md)为输入，独立完成核心板、验证底板、基础固件与SDK，不依赖任何特定整机、上位机型号或算法项目。

当前交付物为设计与调研文档，H0进行中且未验收；下列均为计划。状态统一维护在[项目状态与待办](08_项目状态与待办.md)。H0～H6完成基础平台，H7是可选支线，H8基础发布不以H7完成为前提。

## 阶段H0：需求与接口冻结

- 完成H0-00：明确G01～G10要求和P0～P4验证配置，填写节点数、协议、报文负载、频率、数据有效期、停止时限和环境。
- 区分支持的物理层、设备协议、控制模式和并发组合；建立引脚、定时器、DMA及内存资源矩阵。
- 复查STM32H743VIH6的全部AF、时钟、DMA及电源配置，记录是否维持TFBGA100；换封装需重新核对完整映射。
- 解决RGB与IMU加热共用TIM8时间基问题。
- 明确IMU、加热、存储等配置的必需/可选关系，确定关键器件、尺寸、板层及制造约束。
- 复核J1/J2针序、连接器配对、机械高度、电源预算、默认状态和预留脚纪律。
- 定义通用验证底板：电源与保护、串口/CAN物理层、身份、安全握手与测试接口。

完成标准：需求、资源分配、器件与电气/机械约束相互对应；拟发布配置的验收阈值已数值化，未覆盖能力明确标注。

## 阶段H1：核心板原理图与PCB

评审顺序：MCU电源/去耦 → 时钟/启动/调试 → 双电源与防反灌 → 采集与存储 → 板间接口/安全 → 布局、热与装配。BGA维持时核查扇出和装配能力。

首批少量验证板。保存可编辑EDA、库版本、BOM、ERC/DRC、生产文件与评审记录，不能用截图代替源工程。

## 阶段H2：核心板Bring-up

```text
短路与阻抗检查 → 限流分电源上电 → NRST/HSE/SWD
→ 最小固件/恢复 → USB与UART → 板间接口电平
→ IMU/ADC → QSPI/TF → 加热与NTC保护 → 状态指示
```

按实际装配配置测试各功能，记录电压、电流、波形、固件及结论。基础上电与默认状态未通过时不连接有动力的负载。

## 阶段H3：BSP、平台服务与安全

- 单调时间、时间戳、MPU/Cache和DMA缓冲所有权。
- 资源配置校验、底板身份、设备注册表及能力声明。
- `SAFE_OFF → INIT → READY → ACTIVE → FAULT`状态机。
- 命令来源仲裁、有效期、任务/通信看门狗和硬件禁止配合。
- 参数、诊断、可恢复升级及有界后台日志。
- 无需IMU/RL的配置可以运行，缺失必需设备只影响明确依赖的能力。

完成标准：P0无动力测试通过，错误配置、超时、复位与异常恢复有可复现证据。

## 阶段H4：上位协议与设备适配

- 版本化协议、PC参考客户端和SDK，明确USB/UART传输与应用语义边界。
- 统一设备ID、时间戳、单位、状态/错误和位置/速度等能力子集。
- 选择串口与CAN两类代表设备/协议，先用模拟器验证解析、调度及故障，再准备真实台架。
- 测量报文开销、处理等待、超时/重试、数据年龄与端到端延迟，校正需求预算。
- 新协议放在适配器中，设备布局通过配置加载；不得修改BSP来适配某台机器人。

完成标准：两种配置可复用平台服务，不支持的命令被明确拒绝，模拟与实测结论分别记录。

## 阶段H5：通用验证底板与物理链路

- 实现供电保护、5V预算、采样、身份、急停/硬件禁止和故障反馈。
- 串口物理层声明电平、方向和默认高阻；CAN声明收发器、终端、帧类型及速率。
- 实现P1/P2单设备台架，再增加节点；验证拔线、错误帧、离线与恢复。
- 完成P3采集/I/O，检查标定、单位、默认输出和资源冲突。

完成标准：台架无未解释复位、总线争用和失控输出；底板与线束工程可复现。开发可与H1～H4并行，但接有动力设备前先完成对应保护验证。

## 阶段H6：多配置与混合负载验证

- 相同核心硬件和平台服务运行串口设备、CAN设备及传感/I/O配置。
- P4逐步加入上位链路、更多总线、采集和后台日志，测量延迟、抖动、CPU、各RAM区域、队列峰值及错误。
- 执行断联、复位、卡死、传感器异常、总线故障、存储异常和急停注入。
- 对每种配置发布节点数、频率、模式、物理条件及限制，不把单总线结果推广为全端口并发。

完成标准：P0～P4及G01～G10有对应证据；SDK示例可重建结果。具体机器人应用可以后续独立开展。

## 阶段H7：可选本地算法/策略

在开发计算机训练或生成算法，H7只运行适配后的推理/控制。完成P5固定输入回放、数值误差、内存及并发时序测试；输出始终经过统一命令与安全层。

完成标准：算法超时、NaN/Inf和越界可拒绝或按配置回退，不影响基础平台。45→128→128→12与200 Hz仅作推理算例，不固定平台设备数或周期。

## 阶段H8：基础平台发布

- 冻结已验证硬件、BOM、接口、固件、参数格式、协议与SDK版本。
- 发布接线、参考底板、适配器开发说明、示例配置、恢复说明及原始测试报告。
- 逐项标注能力为已验证/部分验证/未支持，保留已知限制和负载条件。
- 按[验收方案](04_总结演示与验收.md)完成复现检查；可选H7结果另行发布。
